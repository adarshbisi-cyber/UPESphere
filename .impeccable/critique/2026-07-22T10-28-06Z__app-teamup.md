### Priority Issues

[P0] "My TeamUp" has zero navigation entry points. Navbar.tsx's accountLinks only contains Dashboard/Gradebook; /teamup/mine appears nowhere in the navbar. Fix: add to accountLinks or promote to a signed-in nav item.

[P1] Every TeamUp modal fails basic modal accessibility. UploadModalShell.tsx (shared by all upload/create modals app-wide) has no role="dialog"/aria-modal, no Escape handler, no focus trap, unlabeled close icon. Fix: add these; suggested command /impeccable harden.

[P1] /teamup/students reinvents a worse filter UI — flat 30+ chip list, no categorization, not collapsible, vs TeamFiltersBar/SkillPicker's solved pattern. Suggested command /impeccable layout.

[P2] Destructive "Cancel Team" uses raw browser confirm(). Suggested command /impeccable polish.

[P3] Spinners instead of skeletons across all TeamUp lists, contradicting stated design-system preference. Suggested command /impeccable polish.
